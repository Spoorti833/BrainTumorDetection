# BrainTumorDetection
Developed a deep learning–based brain tumor detection system using a Convolutional Neural Network (CNN). MRI images are preprocessed, resized, and passed through the trained model to perform binary classification. The project leverages TensorFlow, Keras, OpenCV, and NumPy to deliver accurate and efficient predictions.
# ⚙️ Features

• Image preprocessing and normalization

• CNN model training and evaluation

• Flask-based web interface for image upload

• Real-time prediction results

# 🛠️ Tech Stack

• Python

• TensorFlow, Keras

• Flask

• OpenCV

# 🎯 Outcome

Achieved high accuracy in MRI image classification and deployed the model for real-time usage.
